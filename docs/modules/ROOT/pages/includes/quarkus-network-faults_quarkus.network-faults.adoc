[.description]
--
Whether outbound connections are routed through fault-injecting proxies. Decided at build time: when off, the extension registers no interceptor and no proxy.

Off by default. Test classes opt in with `@TestProfile(NetworkFaultsProfile.class)`, whose config overrides set this to `true` for the build made for that profile.
